# 改稿检查清单

改稿时按顺序过一遍，**只改该动的地方**，不要顺手重写作者的语气。

## 1. 先确认三件事，缺一件就问

- 读者是谁（同事 / 客户 / 公开读者 / 上级）
- 这份东西要达成什么（让人点头 / 让人动手 / 让人记住）
- 篇幅和口径的硬约束（多少字、能不能提具体数字和名字）

问不到就按最小假设写，并在开头说明假设。

## 2. 结构

- 第一段能不能独立说清"这是什么、为什么要看"
- 每段只有一个主张，主张句在段首
- 有没有可以整段删掉而不损失信息的部分（有就删）
- 小标题是否动词化（"确认口径"好过"关于口径"）

## 3. 句子

- 一句话一个意思，超过 40 字就找地方断
- 删掉"进行、方面、相关、一定程度、更好地"这类不承载信息的词
- 被动句改主动句，除非执行者确实不重要
- 同类信息用同一句式，读者才不用重新解析

## 4. 事实与口径

- 每个数字有没有出处；没有出处就写"约"或删掉
- 时间、人名、版本号、金额逐字对照原文
- 承诺性表述（"下周上线""一定会"）必须有依据，否则改成条件句

## 5. 收尾

- 最后一段是不是给了明确的下一步（谁、做什么、什么时候）
- 有没有留下"待补充""待确认"却没说是谁来补

## 常见病症速查

| 症状 | 改法 |
| --- | --- |
| 开头铺垫两段还没进正题 | 直接删到第一个有信息量的句子 |
| 通篇"我们认为" | 换成具体判断或证据 |
| 每段都很长且结构相同 | 挑一段拆成列表，或合并两段 |
| 形容词比动词多 | 每个形容词问一遍"证据在哪" |
