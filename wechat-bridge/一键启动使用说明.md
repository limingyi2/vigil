# 知夏微信桥接 - 一键启动 & 开机自启 使用说明

## 文件说明

| 文件 | 作用 |
|------|------|
| `启动桥接.bat` | 一键启动桥接（自动启动微信→等待→启动桥接→崩溃自动重启） |
| `设置开机自启.bat` | 把启动脚本加到开机启动项，可选配置自动登录 |

## 首次使用步骤

### 1. 修改路径配置

用记事本打开 `启动桥接.bat`，修改顶部的配置区：

```bat
set "BRIDGE_DIR=C:\Users\Administrator\Desktop\wechat-bridge"   ← 桥接脚本所在目录
set "BRIDGE_SCRIPT=wxauto_bridge.py"                           ← 桥接脚本文件名
set "WECHAT_DIR=D:\Weixin418\4.1.8.28"                         ← 微信安装目录
set "WECHAT_EXE=Weixin.exe"                                    ← 微信可执行文件名
set "PYTHON_EXE=python"                                        ← Python 命令
```

> 怎么找桥接脚本目录？在桌面上找到桥接脚本的快捷方式，右键→属性，看"起始位置"就是 BRIDGE_DIR。

### 2. 测试一键启动

双击 `启动桥接.bat`，观察：
- 是否自动启动微信（如果没运行）
- 是否启动桥接脚本
- 桥接是否正常运行（日志里有输出）

### 3. 设置开机自启

右键 `设置开机自启.bat` → **以管理员身份运行**，按提示操作：
- 会自动创建开机启动快捷方式
- 询问是否开启自动登录（云服务器建议选 y）

## 开机自启原理

1. 电脑重启 → 自动登录 Administrator（如果开启了）
2. Windows 启动文件夹里的快捷方式自动运行 `启动桥接.bat`
3. `启动桥接.bat` 检查微信是否运行，没运行就启动
4. 等待微信加载完成（15秒）
5. 启动桥接脚本 `python wxauto_bridge.py`
6. 如果桥接脚本崩溃退出，5秒后自动重启

## 常见问题

### Q: 重启后桥接没启动？
A: 检查是否开启了自动登录。如果没开启，重启后停在登录界面，桥接不会启动。需要手动登录桌面后才会启动。

### Q: 微信启动了但桥接连不上？
A: 微信启动需要时间，脚本默认等15秒。如果微信启动慢，修改 `启动桥接.bat` 里的 `timeout /t 15` 改成更大的值（比如30）。

### Q: 怎么停止桥接？
A: 在桥接运行的黑色窗口里按 `Ctrl+C`，然后按 `Y` 确认终止批处理。

### Q: 怎么看桥接日志？
A: 打开 `启动桥接.bat` 同目录下的 `bridge_run.log` 文件。

### Q: 桥接崩溃了会自动重启吗？
A: 会。只要不是正常退出（退出码0），脚本会5秒后自动重启。正常退出（比如你手动 Ctrl+C）不会重启。

### Q: 不想开机自启了怎么办？
A: 按 `Win+R`，输入 `shell:startup`，删除里面的「知夏微信桥接」快捷方式。

## 安全提醒

- 自动登录会把 Administrator 密码存在注册表里，只有云服务器这种专用机器建议开启
- 如果关闭自动登录，重启后需要手动登录桌面，桥接才会启动
- 桥接脚本必须在桌面会话里运行，不能用 SSH 启动（SSH 里看不见微信窗口）
