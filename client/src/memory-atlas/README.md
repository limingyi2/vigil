# Memory Atlas · 记忆星图 Demo

当前版本使用 Three.js / WebGL 2。请在仓库根目录启动本地服务：

```powershell
python -m http.server 8797 --bind 127.0.0.1 --directory client/src/memory-atlas
```

然后访问 `http://127.0.0.1:8797/`。

点击“导入记忆库”可载入 JSON 向量导出。支持数组或 `{ "memories": [...] }`：

```json
{
  "memories": [
    {
      "id": "memory-001",
      "text": "周末喜欢去河边散步。",
      "category": "生活偏好",
      "tags": ["周末", "散步"],
      "created_at": "2026-10-26T09:00:00Z",
      "embedding": [0.12, -0.31, 0.08]
    }
  ]
}
```

每条记录必须有 `text`（也接受 `content` / `memory`）和同维度的 `embedding`（也接受 `vector`）。当前本地 PCA 为了保持交互流畅，单次最多载入 100 条。点与点的位置由向量 PCA 映射到 3D；连线是每个节点的 3 个最近邻，按余弦相似度排序。

本 Demo 不连接数据库或调用嵌入服务。自带星图数据是合成样例；手动新增的记忆用浏览器内本地哈希向量，仅保存在当前浏览器。接入实际记忆库时，导出真实 embedding 的 JSON 即可预览。


当前场景“余烬星云 / Ember Veil”采用原创星云景观纹理、约 16,500 颗 WebGL 实时恒星、独立的 96³ 体积云雾以及三维记忆连线。背景景观使用二维高精度纹理，星群与前景云雾随拖拽呈现不同的视差；星云形状不再受球形约束。最后统一进行辉光和曝光处理。Three.js 0.170.0 已固定并放在 `vendor/` 中，无需 npm 安装。需要支持 WebGL 2 的浏览器。

点击“沉浸观星”可展开画面，点击“返回工作区”或按 Esc 恢复侧栏。页面左上角的“球形版本”可打开保留的 `webgl-sphere.html`；更早的 Canvas 2D 版本仍在 `canvas-2d.html`。

素材在 `assets/ember-veil-nebula.png`，生成方式及完整提示词见 `assets/GENERATION.md`。素材为原创合成星云，不对应实际天文观测目标。记忆统计只计入记忆节点，背景恒星不代表新增的真实记忆。

## 记忆潮汐 · 第二个独立版本

访问 `http://127.0.0.1:8797/memory-tide.html`。这是更偏向日常记忆探索的版本：完整的实时 WebGL 场景、约 31,000 颗装饰星尘、随实际记忆布局生成的光簇、选中时亮起的关联路径，以及分类索引和浮动记忆卡。原版光海使用程序生成的三维场景，并提供可切换的星云增强模式；页面不依赖远程字体。源文件为 `memory-tide.html` 和 `tide-renderer.js`。

“拾起一段记忆”会选中当前筛选中的一条记录；“存入记忆”后可在短暂的提示内撤销刚才的新增；“专注漫游”可收起面板。新增演示记忆仍使用本地哈希向量，导入真实记忆库请使用原模型的向量导出。装饰星尘不计入记忆数量。

原有“余烬星云”及两个更早版本均保留，可由页面顶部切换。

右上角“星云”开关可在原版光海与“Crimson / 绯红星云”之间渐变切换，并在此浏览器记住选择。绯红云壳、黑色尘埃和红色云带由三维 XYZ 密度函数直接生成：160³ 体积场、60,000 个气体采样点、110,000 颗远景装饰恒星和 18 颗中央蓝白恒星。装饰恒星不计入记忆数量。当前模式不读取星云图片，也不使用图片挤出形成形体。旧图片资产及其生成说明保留。它是程序生成的视觉场景，不对应真实天文观测或物理模拟。

开启后，星云由内部向外显现；两组交错的气体体积在三维空间持续向外扩展、淡出，气体光粒也向外流动。云层渲染和星点遮挡共用相同的动态密度采样。启用系统“减少动态效果”时显示静态云体。

底部新增精确的“正面 / 侧面 90° / 背面 180°”视角，选择后暂停自动旋转；立方体按钮“换个角度”依次切换这三个视角。直接拖拽可自由环绕，缩放和记忆悬停、选中连线仍可使用。关闭星云开关返回原版光海。

三维形体实现见 `sculpted-nebula.js`，渲染和遮挡实现见 `tide-renderer.js`。在仓库根目录运行 `node client/src/memory-atlas/verify-nebula.mjs 160` 可检查密度加权的厚度、90% 质量范围、90° 投影面积和三维协方差，防止形体退化为薄片。视觉效果仍需浏览器逐角度检查。

## 深空远景

绯红星云模式增加斜穿天幕的银河星带与五处远景星系，包括蓝白旋臂、暖色中央核和侧视星系。银河由程序生成的暗尘背景与 115,000 个恒星采样组成，星系由带厚度的星盘、旋臂和稀疏星晕组成。实现位于 `deep-sky.js`，无需加载网络图片。

远景与前景采用不同幅度的旋转，形成视差；前景体积云会衰减后方星光。装饰星系不参与记忆搜索、数量统计或相似度计算。星云开关也控制此远景增强层。
