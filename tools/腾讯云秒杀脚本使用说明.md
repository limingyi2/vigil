- 每天两场秒杀：**上午 10:00**、**下午 15:00**
- 活动页面：https://cloud.tencent.com/act

| 文件 | 说明 |

## 使用步骤

### 第一步：首次运行（登录）

```bash
cd F:\Vigil\tools
python tencent_seckill.py
```

脚本会打开浏览器，进入腾讯云活动页面。
- 如果未登录，**请在浏览器中手动登录腾讯云**（扫码或账号密码）
- 登录成功后，**回到终端按回车键**
- 脚本会自动保存 cookie 到 `tencent_cookie.json`，以后运行不需要再登录

### 第二步：定时抢购

脚本启动后会自动计算下一场秒杀时间：
- 如果距离秒杀超过 2 分钟，脚本会等待到提前 2 分钟再启动抢购页面
- 提前 2 分钟启动 3 个并发页面，同时打开活动页面
- 到点后自动点击"立即抢购"按钮
- 抢购成功会自动跳转到订单确认页，请在 60 分钟内完成支付

### 第三步：支付

抢购成功后，浏览器会停在订单确认页：
1. 确认配置（地域、时长）
2. 点击"提交订单"
3. 完成支付（支持微信/支付宝/QQ钱包）

**注意**：订单 60 分钟内未支付会自动取消，请尽快支付。

## 配置说明

编辑 `tencent_seckill_config.json`：

```json
{
  "activity_url": "https://cloud.tencent.com/act",        // 活动页面地址
  "target_keyword": "轻量应用服务器",                       // 目标商品关键词
  "target_price": "38",                                     // 目标价格
  "seckill_times": ["10:00", "15:00"],                     // 秒杀时间
  "提前启动秒数": 120,                                       // 提前多少秒启动抢购页面
  "点击间隔毫秒": 100,                                       // 每次点击间隔（毫秒）
  "最大重试次数": 50,                                        // 最大重试次数
  "并发页面数": 3,                                           // 并发抢购页面数
  "cookie_file": "tencent_cookie.json",                      // cookie 保存文件
  "headless": false,                                         // 是否无头模式（建议 false，方便看过程）
  "地域": "广州",                                            // 目标地域（广州/上海/北京）
  "时长": "1年"                                              // 购买时长
}
```

## 提高成功率的技巧

1. **提前登录**：首次运行时登录好，cookie 会保存，后续自动加载
2. **网络要好**：用有线网络或 5G，延迟越低越好
3. **并发页面**：默认 3 个页面同时抢，可以调到 5 个（但太多可能被风控）
4. **提前启动**：默认提前 2 分钟启动页面，可以调到 3 分钟，确保页面加载完成
5. **点击间隔**：默认 100ms，可以调到 50ms（更快，但可能触发风控）
6. **多账号**：如果有多个腾讯云账号，可以复制多份脚本分别运行

## 注意事项

1. **限购规则**：38元秒杀价仅限**产品新用户**（该产品无订单记录），同一实名认证主体限购 1 台
2. **支付时限**：下单后 60 分钟内必须支付，否则订单自动取消
3. **不支持代金券**：秒杀商品不能使用代金券/优惠券
4. **不支持退货**：秒杀商品不支持 5 天无理由退货
5. **风控风险**：频繁点击可能触发腾讯云风控，导致账号被限制，建议合理设置参数
6. **cookie 有效期**：腾讯云 cookie 一般有效期 7-30 天，过期后需要重新登录

## 常见问题

**Q: 脚本提示"未找到抢购按钮"怎么办？**
A: 可能是活动页面结构变了，或者还没到秒杀时间。检查活动页面地址是否正确，确认商品卡片上有"立即抢购"按钮。

**Q: 抢购成功但没跳转到订单页？**
A: 可能是弹出了新窗口，检查浏览器是否有新标签页。脚本会自动检测订单页内容。

**Q: cookie 过期了怎么办？**
A: 删除 `tencent_cookie.json` 文件，重新运行脚本，手动登录一次即可。

**Q: 可以抢其他商品吗？**
A: 可以，修改配置文件里的 `target_keyword` 和 `target_price` 即可。

**Q: 可以在服务器上运行吗？**
A: 可以，但需要安装桌面环境或使用 xvfb。建议在本地电脑运行，方便手动登录和支付。
