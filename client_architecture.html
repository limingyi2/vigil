📌 关键数据流
① 聊天消息：客户端 UI → 渲染层 → 主进程（加 Token）→ 网络层 → 云端 brain → 返回回答 → 原路回到 UI
② 本地操控：AI 回复中包含"执行命令"指令 → 主进程 child_process 执行 → 结果返回给 AI → AI 组织回答
③ 手机互通：客户端和手机 App 都连云端 brain 的同一账号 → 聊天记录实时同步（WebSocket 推送）
④ 身份认证：首次登录用 brain_token 验证 → 客户端生成设备 ID → 跟手机 App 绑定同一用户 → 后续请求带 Token
⑤ 桌宠 Live2D：渲染层用 Live2D Cubism SDK 加载模型 → 主进程根据 AI 情绪/指令触发动作 → 桌面置顶透明窗口显示
