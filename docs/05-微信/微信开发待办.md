## 一、项目概述

### 1.1 目标
让林知夏（或指定人设）在微信上以真人方式聊天，包括：
- 私聊陪伴（一对一日常聊天）
- 群聊接话（在小群里插科打诨、活跃气氛）
- 多媒体消息（图片、语音、表情包、文件）
- 跟 App/客户端共用同一套大脑（渠道隔离，记忆和历史独立）

### 1.2 当前架构
```
微信客户端（真实微信窗口，wxauto4 UI 自动化驱动）
    ↓ 收到消息
wxauto_bridge.py（桥接服务，跑在腾讯云 Windows Server）
    ↓ HTTP 调云端大脑
/api/chat  {"src": "wechat"}
    ↓
林知夏大脑（阿里云，8788）—— 用 wechat 渠道的人设与记忆
```

- **桥接服务**：`_split/zhixia-wechat-bridge/wxauto_bridge.py`
- **部署位置**：腾讯云 Windows Server（已部署运行）
- **备份方案**：VirtualBox 虚拟机（`_split/zhixia-wechat-bridge/vm/`）
- **备选方案**：iPad 协议（dow-ipad-859，需缘分码付费，未采用）

### 1.3 跟其他渠道的关系
| 渠道 | 人设 | 记忆 | 聊天历史 | 工具 |
|---|---|---|---|---|
| App/客户端 | 林知夏（主） | 独立 | 独立 | 30个（含 local_*） |
| 微信私聊 | preset_group 或林知夏 | 独立 | 独立 | 6个（无 local_*） |
| 微信群聊 | preset_group（群聊专用） | 独立 | 独立 | 6个 |

- 生活流、日记**故意共用**——同一个现实身份
- 记忆和聊天历史按渠道隔离

## 三、分阶段开发计划

### 阶段0：稳定性加固（前置依赖）
**目标**：让微信桥接服务稳定运行，掉线能自动恢复，有监控告警。
**预计时间**：3天
**前置依赖**：无

#### 0.1 桥接服务保活
- [ ] 0.1.1 桥接服务崩溃自动重启（Windows 计划任务或进程守护）
- [ ] 0.1.2 微信窗口掉线检测（wxauto 连接断开时自动重连）
- [ ] 0.1.3 微信被挤下线时告警（发通知到 App 或邮件）
- [ ] 0.1.4 大脑 API 不通时降级（缓存消息，恢复后补发）

#### 0.2 监控与日志
- [ ] 0.2.1 桥接服务运行状态监控（心跳、内存、CPU）
- [ ] 0.2.2 消息收发统计（每日收发条数、成功率、延迟）
- [ ] 0.2.3 错误日志收集（wxauto 异常、API 错误、网络错误）
- [ ] 0.2.4 微信登录状态监控（在线/离线/被挤）

#### 0.3 防封号基础
- [ ] 0.3.1 消息频率限制（默认 30条/分钟，可配置）
- [ ] 0.3.2 发送间隔随机化（模拟真人打字速度，1-3秒随机延迟）
- [ ] 0.3.3 深夜静默（23:00-08:00 降低回复频率或不主动说话）
- [ ] 0.3.4 重复消息检测（同一条内容 5 分钟内不重复发）

**验收标准**：
- 桥接服务连续运行 7 天不崩溃
- 微信掉线后 5 分钟内自动恢复
- 每日有运行状态报告
- 消息频率不超过 30条/分钟

### 阶段1：私聊功能完善
**目标**：微信私聊体验跟 App 对齐，支持多媒体消息。
**预计时间**：1周
**前置依赖**：阶段0

#### 1.1 文字消息优化
- [ ] 1.1.1 长消息自动分段（微信单条消息长度限制，超过自动分多条发）
- [ ] 1.1.2 消息排版优化（Markdown 转纯文本，保留换行和列表）
- [ ] 1.1.3 @提及支持（回复时可以 @对方）
- [ ] 1.1.4 引用回复支持（引用对方的某条消息回复）

#### 1.2 图片消息
- [ ] 1.2.1 接收图片（wxauto 读取图片，保存到临时目录）
- [ ] 1.2.2 图片发给大脑（调视觉模型 Qwen3-VL 识图，结果传给大脑）
- [ ] 1.2.3 发送图片（大脑回复里的图片 URL，下载后用 wxauto 发送）
- [ ] 1.2.4 表情包识别（接收表情包，识别情绪，传给大脑）

#### 1.3 语音消息
- [ ] 1.3.1 接收语音（wxauto 读取语音文件，转文字用 Whisper 或云端 ASR）
- [ ] 1.3.2 语音转文字后传给大脑
- [ ] 1.3.3 发送语音（大脑回复用 TTS 转语音，wxauto 发送语音消息）
- [ ] 1.3.4 语音开关（用户可以选择要文字还是语音回复）

#### 1.4 文件传输
- [ ] 1.4.1 接收文件（wxauto 接收文件，保存到临时目录）
- [ ] 1.4.2 文本文件内容读取（.txt/.md/.json 等，内容传给大脑）
- [ ] 1.4.3 文件下载链接生成（大脑回复里的文件，上传后发链接）
- [ ] 1.4.4 文件大小限制（超过 10MB 提示用户）

#### 1.5 表情包/贴纸
- [ ] 1.5.1 发送表情包（大脑指定表情包名，从表情包库选图发送）
- [ ] 1.5.2 表情包库管理（跟 App 共用表情包库）
- [ ] 1.5.3 表情包情绪匹配（根据回复情绪自动选表情包）
- [ ] 1.5.4 收藏表情包（用户发的表情包可以收藏到库）

**验收标准**：
- 私聊能正常收发文字、图片、语音、文件、表情包
- 图片能被大脑识别并据此回复
- 语音能转文字，文字能转语音
- 长消息自动分段不报错

**前置依赖**：阶段0、阶段1

- [ ] 2.1.2 群聊消息过滤（只处理指定群，其他群忽略）
- [ ] 2.1.3 发送者识别（识别是谁发的消息，记录群成员）
- [ ] 2.1.4 @提及识别（识别是否 @了她或提到她的名字）

#### 2.2 群聊接话策略

- [ ] 2.2.3 接话时机判断（话题相关、冷场、被@时才接话）
- [ ] 2.2.4 刷屏抑制（群里她自己的发言占比超过阈值时闭嘴）

#### 2.3 群聊互动功能
- [ ] 2.3.1 @她时优先回复（被@必须回，除非在忙）

- 被@时优先回复
- 群聊人设跟私聊不同（更活泼）

## 四、安全与风控

### 4.1 封号风险防控
| 机制 | 实现阶段 | 说明 |
|---|---|---|
| 消息频率限制 | 阶段0 | 默认 30条/分钟，可配置 |
| 发送间隔随机化 | 阶段0 | 模拟真人打字速度 |
| 深夜静默 | 阶段0 | 23:00-08:00 降低频率 |
| 重复消息检测 | 阶段0 | 5分钟内不重复发同一条 |
| 小号专用 | 部署时 | 不要用主力微信号 |
| 敏感词过滤 | 阶段1 | 政治/色情/违法内容不发 |
| 群聊退群保护 | 阶段2 | 被群主踢了之后自动停止该群 |

### 4.2 隐私保护
| 机制 | 说明 |
|---|---|
| 聊天记录加密 | 本地存储加密，云端传输 HTTPS |
| 图片/语音临时文件 | 处理完自动删除，不长期保存 |
| 群成员信息 | 只存昵称和发言记录，不存个人隐私 |
| 用户授权 | 加入群聊前需要用户明确同意 |

## 五、风险和注意事项

### 5.1 技术风险
| 风险 | 影响 | 缓解措施 |
|---|---|---|
| wxauto 微信版本兼容 | 微信更新后桥接失效 | 锁定微信版本，更新前先测试 |
| UI 自动化不稳定 | 偶尔漏消息或发不出去 | 重试机制 + 错误日志 + 告警 |
| 微信被封号 | 整个微信渠道失联 | 小号专用 + 频率控制 + 敏感词过滤 |
| 大脑 API 不通 | 消息发不出去 | 本地缓存 + 恢复后补发 |
| 云服务器到期 | 桥接服务停掉 | 虚拟机备份方案，随时可切 |

### 5.2 注意事项
- **不要用主力微信号**：所有非官方方案都有封号风险，用小号专门跑 bot
- **UI 自动化会占微信前台**：桥接服务运行时，微信窗口不能最小化到托盘（可以被其他窗口遮挡，但不能最小化）
- **群聊要先征得群主同意**：不要私自把 bot 拉进别人的群
- **微信渠道的记忆跟 App 隔离**：微信里聊的事不会出现在 App 里，反之亦然
- **桥接服务跑在腾讯云**：跟大脑（阿里云）是两台服务器，网络延迟要考虑

## 六、文件结构

```
_split/zhixia-wechat-bridge/
├── wxauto_bridge.py          # 桥接本体：读消息 → 问大脑 → 发消息
├── gate.py                    # 本地闸门（桥接服务端）
├── brain-plugin/gate.py       # 云端发言闸门（装到 brain/plugins/）

│   └── wxbridge.local.example.json  # 脱敏配置示例
├── docs/
│   ├── 部署手册.md
│   ├── 技术约束.md
│   └── 虚拟机脚本说明.md
└── vm/                        # 虚拟机备份方案
    ├── zx.cmd                 # 主入口：一键装包 → 开隧道 → 起桥接
    ├── GO.cmd                 # 解压安装包 + 建桌面快捷方式
    ├── vbox/                  # 装 VirtualBox / 建虚拟机
    └── runtime/               # 日常运行：隧道保活 + 自测
```
