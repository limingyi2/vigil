# P8.2 · WeChat Bridge 插件化迁移清单

本文件是 P8.1（桌面端去掉远程 Brain 依赖）的交接物：**这一轮没有删任何微信功能**，
只是把桌面客户端和远端解绑了。下面这些能力仍然属于「微信」，留到 P8.2 按插件迁移。

## 一、文件仍然存在、这一轮没有删的

| 位置 | 作用 | 迁移时的归属 |
| --- | --- | --- |
| `wechat-bridge/wxauto_bridge.py` | 微信登录、收发消息、群/私聊识别 | 插件运行时（独立进程） |
| `wechat-bridge/brain-plugin/gate.py` | 群里 @ 才答的硬闸门（说话档位 1 档） | 插件随包的 brain 侧组件 |
| `wechat-bridge/config-example/wxbridge.local.example.json` | 桥接配置（brain_urls / brain_token / chat_name） | 插件自己的加密配置，与主配置隔离 |
| `wechat-bridge/vm/*` | 桥接运行机上的启动器与看护脚本 | 插件安装文档，不进客户端 |
| `brain/ws_forward.py` + `client/electron/forward.js` | 云端 → 本机的「微信消息交给本机大脑答」长连 | 插件可选能力（默认关闭） |

注：`wechat-bridge/**` 与 `brain/plugins/gate.py` 这一轮**一行都没改**，桥接机上的部署照旧能跑。
`client/electron/forward.js` 文件还在，但客户端 P8.1 起不再 `require` 它，也不会建立任何转发长连 ——
"桌面端一开就替微信连云端"这件事已经停了，能力本身留给 P8.2 做成插件。

## 二、仍然算「远程依赖」的（P8.2 要收进插件）

1. **桥接连接的目标地址**：`brain_urls[0]` 走本机 SSH 隧道（18787），
   `brain_urls[1]` 是云机 `8788` 公网兜底。端口 8788 写死在 `brain/server.py`。
   → 插件化后改为插件的 `endpoint` 配置项，允许"只连本机"。
2. **主人钥匙**：`brain_token` 必须与所连大脑的 `config.json` 里的 `brain_token` 一致。
   → 改为插件独立凭据槽（不进主客户端配置、不进日志）。
3. **渠道账号数据**：微信渠道的人设、记忆分区（`chan=wechat/wechat_group`）、
   说话档位（`features_by_src.wechat*`）、统计与历史 —— 都存在**桥接所连的那台大脑**里。
   → 插件启用时声明它需要哪些渠道分区，禁用时不加载。
4. **双大脑路由**：`wechat_route = cloud | local`（`POST /api/route`）决定微信消息由谁作答。
   桌面端 P8.1 起不再提供这个开关（改了也影响不到远端），开关的位置回到插件配置里。
5. **`ws_forward` 长连**：云端大脑把消息转给本机大脑需要 WS + 心跳 + 迟到答案回写历史。
   → 插件的一个可选子能力，默认关闭；不启用插件时客户端不建立任何长连。

## 三、P8.2 的边界约定（本轮已经建立）

- **桌面客户端只连本机 Brain**：`connectionBase()` 只返回 sidecar 地址；
  渲染层传任何 `base` 都会被主进程拒绝（凭据外传口已封）。
- **不自动轮询远端**：`pollOnce()` 只问我方 Brain；云端双轮询已删除。
- **不自动同步**：`sync_client.cloud()` 需要显式 `sync.desktop_sync: true` 才生效，
  没有任何代码写这个键；sidecar 也不再注入 `VIGIL_CLOUD_URL/TOKEN`。
- **不装插件 = 不启动微信任务**：客户端目前不 require `forward.js`，
  也不再 spawn 任何桥接进程。
- **插件 UI 复用**：`brain/plugins/*.py` + 插件市场页面（`client/src/js/pages.js` 的
  `ability` 页）已经支持安装/启停/前端注入，WeChat Bridge 按同一套 manifest 落地即可。

## 四、迁移时的验收点

1. 未安装插件：客户端进程列表里没有桥接进程、没有到 8788 的出站连接。
2. 安装并启用插件：登录、收发消息、群 @ 门槛与现在一致。
3. 禁用插件：长连断开、插件凭据不落主配置、不影响本机聊天与创作。
4. 插件配置迁移：旧 `wxbridge.local.json` 能导入，凭据走插件自己的存储。
