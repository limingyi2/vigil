# 插件市场使用指南

## 一、仓库信息

| 项 | 值 |
|---|---|
| 托管平台 | 阿里云 CodeUp（云效 DevOps） |
| 仓库地址 | `https://limingyi2-cn-hangzhou.devops.aliyuncs.com/codeup/vigil-plugins.git` |
| 可见性 | 私有 |
| 本地镜像 | `F:\vigil-plugins\` |
| 主分支 | main |

> 为什么用阿里云 CodeUp 而不是 GitHub：国内裸连稳定，不需要代理，git pull/push 速度快。GitHub 仓库可作为备份保留。

---

## 二、整体架构

```
阿里云 CodeUp 私人仓库 (vigil-plugins)
    │  git push（开发者发布新插件）
    ▼
本地市场仓库 (F:\vigil-plugins\)  ← git clone 的镜像
    │  客户端点「刷新市场」→ 后端执行 git pull
    ▼
plugin_market 插件 (brain/plugins/plugin_market.py)
    │  读取本地 market.json → 前端展示卡片
    │  安装 = 从本地仓库复制目录到 brain/plugins/
    │  卸载 = 删除 brain/plugins/ 下的目录
    ▼
plugin_host.load(force=True)  ← 热重载
    │  重新扫描 → 清理模块缓存 → 重新注册
    ▼
路由 / 工具 / 钩子 全部动态生效
```

**关键点**：客户端不直接连阿里云 API，所有 git 操作都在后端通过本地镜像仓库完成。后端只操作本地文件系统，不关心 remote 是 GitHub 还是阿里云。

## 三、第一次连接（克隆仓库 + 认证）

### 步骤 1：获取 CodeUp 克隆账号密码

阿里云 CodeUp 的 HTTPS 克隆**不是用阿里云账号密码**，需要专门的克隆账号：

1. 登录 https://codeup.aliyun.com
2. 右上角头像 → **个人设置**
3. 左侧找 **「HTTPS 克隆账号」** 或 **「密码管理」**
4. 查看/生成：
   - **克隆账号**（用户名）
   - **克隆密码**（点「生成」或「重置」获取）
5. 参考文档：https://help.aliyun.com/document_detail/158880.html

### 步骤 2：克隆仓库到本地

```powershell
cd F:\
git clone https://limingyi2-cn-hangzhou.devops.aliyuncs.com/codeup/vigil-plugins.git
```

第一次 clone 会弹出登录框，输入上面的**克隆账号**和**克隆密码**。Windows 的 Git Credential Manager 会记住，以后不用再输。

> 如果已经克隆过 GitHub 版本，不需要重新 clone，直接改 remote：
> ```powershell
> cd F:\vigil-plugins
> git remote set-url origin https://limingyi2-cn-hangzhou.devops.aliyuncs.com/codeup/vigil-plugins.git
> git push -u origin main
> ```

### 步骤 3：验证连接

```powershell
cd F:\vigil-plugins
git ls-remote origin
```
能看到 `refs/heads/main` 就说明连接成功。

## 四、上传新插件到市场（开发者操作）

### 步骤 1：写好插件

按《Vigil插件开发指南》写好插件，目录结构：
```
my_plugin/
├── __init__.py      # 后端逻辑（必填）
├── frontend.js      # 前端代码（可选）
├── frontend.css     # 前端样式（可选）
└── README.md        # 插件说明
```

### 步骤 2：放进本地市场仓库

把插件目录复制到 `F:\vigil-plugins\plugins\` 下：
```powershell
Copy-Item -Recurse my_plugin F:\vigil-plugins\plugins\
```

### 步骤 3：更新 market.json

编辑 `F:\vigil-plugins\market.json`，在 `plugins` 数组里加一条：
```json
{
  "name": "my_plugin",
  "desc": "一句话描述这个插件干什么",
  "version": "1.0.0",
  "author": "你的名字",
  "tags": ["标签1", "标签2"],
  "path": "plugins/my_plugin",
  "readme": "plugins/my_plugin/README.md",
  "has_frontend": true
}
```

字段说明：
| 字段 | 必填 | 说明 |
|---|---|---|
| name | ✅ | 插件名，唯一，英文小写+下划线 |
| desc | ✅ | 一句话描述，前端卡片展示 |
| version | ✅ | 语义化版本号，如 1.0.0 |
| author | ✅ | 作者名 |
| tags | ✅ | 标签数组，用于分类筛选 |
| path | ✅ | 插件在仓库里的相对路径 |
| readme | ❌ | README 相对路径 |
| has_frontend | ❌ | 是否带前端代码，true/false |

### 步骤 4：提交并推送

```powershell
cd F:\vigil-plugins
git add .
git commit -m "add: my_plugin 插件"
git push
```

推送完成后，所有用户在客户端点「刷新市场」就能看到新插件。

## 五、安装插件（用户操作）

### 方法一：客户端可视化安装（推荐）

1. 打开客户端 → 左侧导航点「插件市场」
2. 找到要安装的插件卡片
3. 点「安装」按钮
4. 等待 1-2 秒，按钮变成「卸载」= 安装成功
5. **立即生效，不需要重启**（热加载）

### 方法二：手动安装

1. 从市场仓库复制插件目录到 `F:\Vigil\brain\plugins\`
2. 重启 brain（或调用 `POST /api/plugins/reload`）

## 七、更新插件

### 开发者发布更新

1. 修改插件代码
2. 更新 `market.json` 里对应插件的 `version` 字段（如 1.0.0 → 1.0.1）
3. `git add . && git commit -m "update: my_plugin v1.0.1" && git push`

### 用户更新

1. 客户端 → 「插件市场」→ 点顶部「刷新市场」按钮
2. 找到要更新的插件 → 点「安装」（覆盖安装，自动删除旧版本）
3. 热重载生效

> 目前没有版本对比和"有更新"标记，后续可以加。当前做法是重新安装即更新。

## 八、热加载原理

### 为什么能热加载？

Vigil 的插件系统从设计上就是**全动态**的，没有任何一次性注册的静态资源：

| 组件 | 机制 | 热加载时 |
|---|---|---|
| **路由** | 每次请求动态查 `plugin_host.route_table()` | 新路由自动生效，旧路由自动消失 |
| **工具** | `_reindex_tools()` 每次 load 后重建索引 | 新工具立即对模型可见 |
| **钩子** | 每轮对话遍历 `_registry` 动态调用 | 新钩子立即参与，旧钩子立即移除 |
| **模块缓存** | load() 清理 `sys.modules` 里的 `zxplug_*` | 重新 import 拿到新代码 |
| **功能开关** | `_sync_features()` 每次 load 后重新登记 | 新插件的 FEATURE 自动出现在开关页 |

### 热加载执行流程

```
install/uninstall API 被调用
    │
    ▼
复制/删除插件目录
    │
    ▼
plugin_host.load(force=True)
    │
    ├─ 1. 加锁 (_lock)，防止并发
    ├─ 2. 重新扫描 plugins/ 目录
    ├─ 3. 对每个插件调用 _load_one()
    │      ├─ importlib 导入模块（模块名 zxplug_xxx）
    │      ├─ 读取 NAME/DESC/FEATURE/ROUTES/TOOL_SPECS/钩子
    │      └─ 读取 frontend.js/frontend.css（目录型插件）
    ├─ 4. 清理 sys.modules：删掉不在新列表里的 zxplug_* 模块
    ├─ 5. 清空 _registry，填入新扫描到的插件
    ├─ 6. _reindex_tools()：重建工具索引
    ├─ 7. _sync_features()：重新登记功能开关
    └─ 8. 写日志
    │
    ▼
返回 {"ok": true, "msg": "安装成功，已热重载生效"}
```

### 前端热加载

插件的前端代码（frontend.js/css）是通过 `/api/plugins/frontend` 接口动态拉取的：

1. 客户端启动时调用 `loadPluginFrontends()`
2. 拉取所有已启用插件的 frontend.js/css
3. 用 `executeJavaScript` 注入到渲染进程（绕过 CSP）
4. 每 10 秒轮询一次版本号，变了就 `location.reload()`

所以**安装带前端的插件后，需要刷新一下客户端页面**（或等 10 秒自动刷新），前端代码才会注入。后端逻辑是立即生效的。

### 热加载的限制

1. **正在执行中的插件代码不会被中断**——如果插件的钩子正在跑，热加载后这一轮还是用旧代码，下一轮才用新代码
2. **插件持有的全局状态会丢失**——热加载会重新 import 模块，模块级变量会重置
3. **前端注入需要页面刷新**——后端立即生效，前端等 10 秒自动刷新或手动刷新
4. **插件的 start() 钩子会重新执行**——热加载相当于重新启动插件，如果 start() 里有初始化逻辑（如建定时器），会重复执行。插件作者需要在 start() 里做幂等处理

## 九、常用 API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/market/list` | 市场插件列表 + 已安装标记 |
| POST | `/api/market/install` | 安装插件，body: `{"name": "插件名"}` |
| POST | `/api/market/uninstall` | 卸载插件，body: `{"name": "插件名"}` |
| POST | `/api/market/refresh` | git pull 更新本地市场仓库 |
| GET | `/api/plugins` | 已安装插件列表 + 开关状态 |
| POST | `/api/plugins/reload` | 手动触发热重载 |

## 十、常见问题

**Q: 安装后插件没生效？**
A: 检查 brain 日志有没有报错。常见原因：插件代码有语法错误、插件目录缺少 `__init__.py`、插件名与已有插件冲突。

**Q: 前端页面没出现？**
A: 带前端的插件安装后需要等 10 秒自动刷新，或手动刷新客户端页面。后端逻辑是立即生效的。

**Q: 市场里看不到新插件？**
A: 点「刷新市场」按钮触发 git pull。如果还是看不到，检查本地仓库 `F:\vigil-plugins\market.json` 里有没有这条记录。

**Q: 卸载后插件还在运行？**
A: 正在执行中的钩子不会被中断，这一轮结束后就不会再调用了。如果插件建了定时器，需要插件作者在卸载时清理（目前没有统一的卸载钩子，后续可以加）。

**Q: 能在市场里放私人插件吗？**
A: 可以，仓库本身就是私有的（阿里云 CodeUp 私有仓库），只有你能访问。插件内容也不会公开。

**Q: git push 提示认证失败？**
A: 阿里云 CodeUp 的 HTTPS 克隆用的是**克隆账号密码**，不是阿里云主账号密码。去 CodeUp 右上角头像 → 个人设置 → HTTPS 克隆账号，查看或重新生成克隆密码。然后在 Windows 凭据管理器里更新旧密码，或执行 `git push` 时重新输入。

**Q: 点「刷新市场」报错？**
A: 「刷新市场」本质是在 `F:\vigil-plugins` 执行 `git pull`。报错常见原因：
- 网络不通（检查能不能访问 codeup.aliyun.com）
- 认证过期（重新输入克隆账号密码）
- 本地有未提交的改动（先 commit 或 stash）
- 分支冲突（手动 `cd F:\vigil-plugins && git pull` 看具体报错）

**Q: 克隆账号密码忘了怎么办？**
A: 去 CodeUp → 个人设置 → HTTPS 克隆账号，点「重置密码」生成新密码。旧密码立即失效。

**Q: 想切换回 GitHub 或其他 git 平台？**
A: 插件市场不绑定特定平台，只需要改本地仓库的 remote 地址：
```powershell
cd F:\vigil-plugins
git remote set-url origin <新仓库地址>
git push -u origin main
```
后端代码一行都不用改，因为它只操作本地 git 仓库。

**Q: 换电脑了怎么重新连接？**
A: 1. 装 git；2. `git clone https://limingyi2-cn-hangzhou.devops.aliyuncs.com/codeup/vigil-plugins.git F:\vigil-plugins`；3. 输入克隆账号密码；4. 启动 brain，插件市场自动连上。不需要其他配置。
