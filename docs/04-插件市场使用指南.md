# Brain 插件市场：GitHub 默认源与独立安装目录

## 用户安装方式

Vigil 插件市场默认读取公开目录：
- Catalog: `https://raw.githubusercontent.com/limingyi2/vigil-plugins/main/market.json`
- Wallpaper 制品：`plugins/wallpaper/wallpaper-3.0.0.zip`

安装版不需要手动配置开发机路径，也不要求用户预先 clone 插件仓库。打开客户端「能力与扩展 → 插件市场」，点「刷新市场」，即可看到 Wallpaper Engine；点击「安装」后，Vigil 会下载 ZIP，校验制品 SHA-256、Manifest、协议、权限和逐文件 SHA-256，再复用 Brain 插件安装器的静态结构检查与事务提交。

安装成功后，Wallpaper 会触发本地 Brain 重启，再刷新客户端以加载它的前端页面。其他插件会提示按返回消息重启 Brain 后生效。

## 本地开发者覆盖源

如需使用自己的本地 Git 市场仓库，可在运行目录的 `config/config.json` 配置 `market_repo`。该值是本地 Git 工作副本路径，刷新会执行 `git pull --ff-only`。配置本地仓库后，本地源优先；移除该设置即回到默认 GitHub 市场。

## 代码与安装包隔离

- 核心内置插件源码放在 `brain/plugins/`。
- 可公开分发的市场插件包发布在独立的 `vigil-plugins` 仓库，不由 Brain 启动加载器扫描，也不打进 Brain / Electron 安装包。
- 用户安装的插件放在运行时 `brain/data/installed_plugins/`，不写入跟踪源码的 `brain/plugins/`；该目录受 `.gitignore` 保护，且不会被 `deploy/brain/vigil-brain.spec` 收集。
- Wallpaper 使用原来的 Brain 插件（`__init__.py`、`frontend.js`、`frontend.css`），不是 Electron 桌面扩展包。客户端只保留通用的插件前端加载与媒体资源桥，不再提供专用的 Wallpaper 扩展安装页、扩展宿主或独立扩展包构建器。

插件包安装后会按 Vigil Brain 插件协议加载。哈希和 Manifest 校验用于确认制品内容完整且与市场条目一致；只安装你信任的市场条目。
