## 一、背景与目标

**背景**：当前微信桥接 (`wxhook_bridge.py`) 仅处理纯文本消息（`if etype != 1: return`），群内分享的抖音视频、文章链接等以 appmsg 卡片（type=49）进入时直接被丢弃，导致 AI「看不到」这些内容。

**目标**：在保留 DeepSeek 作为主模型的前提下，引入小米 MiMo-V2.6-Flash 作为「感知工具」，让 AI 能够理解群内分享的链接和视频内容，并生成符合人设的回复。

---

## 二、现状诊断

| 模块 | 当前状态 | 问题 |
|---|---|---|
| 桥接 wxhook_bridge | `_handle()` 中 `if etype != 1: return` | 分享卡 (type=49) 被直接丢弃 |
| 群触发 _should_reply_group | 仅认 @知夏/关键词 | 分享卡本身不带 @，需放宽触发 |
| 大脑 model_hub | 仅配置 DeepSeek | 无 MiMo 供应商 |
| 感知层 | 无 | 无法解析 URL/视频内容 |

---

## 三、方案总览

**架构原则**：MiMo 只当感知工具不当主脑——摘要作为工具结果塞上下文，人设/记忆/说话风格全在 DeepSeek 侧，群友感知不到后面换了模型。

```
微信群 → wxhook(抽分享卡) → 大脑 /api/chat 
      → URL 分诊 → MiMo 看视频/网页抽正文 
      → DeepSeek 生成回复 → 回发群
```

**两条感知路径**：
- **抖音视频**：解析无水印直链 → MiMo `video_url` 直传 (fps=1) → 500~1000 字摘要
- **普通网页**：trafilatura 抽正文（免模型，零成本）
- **B 站视频**：view API + CC 字幕（免模型）

## 五、每条消息处理流程（6 步）

```
① wxhook 收到 type=49 分享卡（目前卡死在这一步）
② 桥接抽出标题/描述/短链 → POST /api/chat
③ 大脑正则分诊 URL 类型：抖音 / B站 / 普通网页
④ 感知层分路干活：
   - 抖音 → MiMo video_url 直链 fps=1 拿 500~1000 字摘要
   - 普通网页 → trafilatura 抽正文（免模型）
   - B 站 → view API + 字幕（免模型）
⑤ DeepSeek 生成：人设 + 群上下文 + 分享文本 + 感知摘要 → 群聊风格回复
⑥ 桥接回发群
```

**兜底链**：
- 直链失效 → 下载 mp4 转 Base64(≤50MB) 传 MiMo
- MiMo 超时 → 降级只用 title/desc 硬答，链路不断

- DeepSeek V3.2：输入 2/M 未命中、0.2/M 命中、输出 3/M

### 端到端耗时

| 环节 | 耗时 |
|---|---|
| 短链解析 | ~1.5s |
| 下载视频 (8~15MB) | ~2-4s |

| **合计** | **15~40s** |

**优化**：第4步前先回一句「我看下这视频哈」占位，避免群友觉得卡顿

## 七、MiMo API 技术规格（官方 2026-09-22）

### 视频理解
- **支持模型**：mimo-v2.6-flash, mimo-v2.6-pro, mimo-v2.6-pro-ultraspeed, mimo-v2.5
- **传入方式**：
  - 公网 URL：单个 ≤300MB
  - Base64 Data URL：编码串 ≤50MB（格式 `data:{MIME_TYPE};base64,$BASE64_VIDEO`）
  - **不支持本地文件上传**
- **格式**：MP4, MOV, AVI, WMV
- **控制参数**：
  - `fps`: 默认 2，范围 [0.1, 10]，越高越精细但 token 越多
  - `media_resolution`: `default`（平衡）/ `max`（细节）
- **Token 计算**：
  - 音频：≈ 时长秒 × 6.25（90s ≈ 563 tok）
  - 视觉：官方估算函数（90s 1080p fps=2 ≈ 25.9k tok；fps=1 ≈ 13.2k tok）

### 音频理解
- **格式**：MP3, WAV, FLAC, M4A, OGG
- **限制**：URL ≤100MB / Base64 ≤50MB
- **Token**：≈ 时长秒 × 6.25

### ASR 专用（mimo-v2.5-asr）
- **价格**：¥0.5/小时（90s ≈ ¥0.0125）
- **限制**：仅 wav/mp3，Base64 ≤10MB

## 八、风险与合规

| 风险 | 应对措施 |
|---|---|
| 抖音直链有时效/风控 | 兜底：下载→Base64 或转存 OSS |
| SSRF 攻击 | URL 白名单校验，禁打内网 IP |
| 版权/二次分发 | 仅用于「看懂给群里聊」，不存储/转发原视频 |
| 桥接机资源有限 | 解析放大脑（云端），桥接保持轻 |
| 反爬限频 | 同域名 24h 内限抓 50 次，超限走缓存 |
