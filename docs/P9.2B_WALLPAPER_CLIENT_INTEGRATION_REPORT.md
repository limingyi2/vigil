## Changes and repaired lifecycle issue

- Wallpaper and Brain directory plugin UI use the generic isolated plugin UI host and Broker. Plugin source does not execute in the Core renderer.
- Wallpaper's selected resource is displayed in the Vigil client content background in a sandboxed iframe; the settings UI remains a manager and preview. Core interaction remains above the content surface.
- On packaged startup, Core could make its first UI registry request before the bundled Brain became ready. The later successful persona connection did not cause the initial failed registration to be retried. Core now refreshes the UI registry after that successful connection. The packaged E2E fixture can opt into its loopback Fake Brain only when explicit test mode is enabled; packaged production startup continues to use its bundled sidecar.
- Candidate outputs use a unique directory namespace and release verification uses the same namespace as the build.
