# Vigil 客户端设计系统

> Windows Electron 界面的设计参考，保留初稿的排版、颜色与组件约定。实际样式以 client/src/ 下的 CSS 为准。
> 初稿参考：ui-ux-pro-max；旧桌宠场景不属于当前公开安装包。

---

## 一、设计理念

| 原则 | 说明 |
|---|---|
| **AI 原生** | 打字指示器、流式文本、工具调用状态卡片、思考过程可视化 |
| **玻璃拟态** | 毛玻璃背景 + 半透明卡片 + 微妙边框 + 景深层次 |
| **暗色优先** | 默认暗色主题，保护眼睛，突出 AI 回复和二次元元素 |
| **信息密度适中** | 不拥挤也不松散，管理面板用卡片，聊天用气泡 |
| **微动效** | 150-300ms 过渡，hover 反馈，平滑展开，不炫技 |

## 二、配色系统（暗色模式）

基于 skill 推荐的 AI/Chatbot Platform 配色（紫 #7C3AED + 青 #0891B2），转换为暗色模式。

### CSS 变量

```css
:root {
  /* === 主色 === */
  --primary: #8B5CF6;           /* 主色：紫罗兰（比亮色模式稍亮） */
  --primary-hover: #A78BFA;     /* 主色 hover */
  --primary-active: #7C3AED;    /* 主色按下 */
  --on-primary: #FFFFFF;         /* 主色上的文字 */

  /* === 强调色 === */
  --accent: #22D3EE;             /* 强调色：青色（AI 交互/链接/在线状态） */
  --accent-hover: #67E8F9;
  --on-accent: #0C4A6E;

  /* === 二次元点缀 === */
  --pink: #F472B6;               /* 粉色（人设/桌宠/通知徽章） */
  --pink-hover: #F9A8D4;

  /* === 背景层级（从深到浅） === */
  --bg-base: #0A0A0F;            /* 最底层：窗口背景 */
  --bg-surface: #12121A;         /* 表面：侧边栏 */
  --bg-card: #1A1A24;            /* 卡片：内容区卡片 */
  --bg-elevated: #22222E;        /* 浮起：弹窗/下拉菜单 */
  --bg-hover: #2A2A38;            /* hover 状态 */

  /* === 玻璃拟态 === */
  --glass-bg: rgba(26, 26, 36, 0.7);
  --glass-border: rgba(255, 255, 255, 0.08);
  --glass-blur: 20px;
  --glass-shadow: 0 8px 32px rgba(0, 0, 0, 0.3);

  /* === 文字 === */
  --text-primary: #F1F5F9;       /* 主要文字 */
  --text-secondary: #94A3B8;     /* 次要文字（时间/说明） */
  --text-muted: #64748B;          /* 弱化文字（占位符/禁用） */
  --text-inverse: #0F172A;        /* 反色（在亮色背景上） */

  /* === 边框 === */
  --border: rgba(255, 255, 255, 0.08);
  --border-hover: rgba(255, 255, 255, 0.15);
  --border-focus: var(--primary);

  /* === 状态色 === */
  --success: #34D399;             /* 成功/在线 */
  --warning: #FBBF24;             /* 警告 */
  --error: #F87171;               /* 错误/离线 */
  --info: #60A5FA;                 /* 信息 */

  /* === 消息气泡 === */
  --bubble-ai: var(--bg-card);     /* AI 消息气泡 */
  --bubble-user: var(--primary);    /* 用户消息气泡 */
  --bubble-system: transparent;     /* 系统消息 */

  /* === 代码块 === */
  --code-bg: #0D1117;
  --code-border: rgba(255,255,255,0.1);
}
```

### 配色使用规则

| 场景 | 用色 |
|---|---|
| 主按钮/选中态/链接 | `--primary` |
| AI 交互元素/在线状态/流式文字光标 | `--accent` |
| 人设/桌宠/通知红点 | `--pink` |
| 成功/工具调用成功 | `--success` |
| 警告/需确认 | `--warning` |
| 错误/离线/危险操作 | `--error` |
| 窗口背景 | `--bg-base` |
| 侧边栏 | `--bg-surface` + 玻璃拟态 |
| 内容卡片 | `--bg-card` |
| 弹窗/下拉 | `--bg-elevated` |

## 三、字体系统

基于 skill 推荐的 **Tech Startup** 搭配：Space Grotesk（标题）+ DM Sans（正文）。

### 字体导入

```css
@import url('https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&family=Space+Grotesk:wght@400;500;600;700&display=swap');

:root {
  --font-heading: 'Space Grotesk', sans-serif;
  --font-body: 'DM Sans', sans-serif;
  --font-mono: 'JetBrains Mono', 'Fira Code', monospace;
}
```

### 字号规范

| 层级 | 字号 | 字重 | 字体 | 用途 |
|---|---|---|---|---|
| Display | 28px | 700 | Space Grotesk | 页面大标题（极少用） |
| H1 | 22px | 600 | Space Grotesk | 页面标题 |
| H2 | 18px | 600 | Space Grotesk | 卡片标题/区块标题 |
| H3 | 16px | 500 | Space Grotesk | 小标题/列表项标题 |
| Body-L | 15px | 400 | DM Sans | 正文（聊天消息） |
| Body | 14px | 400 | DM Sans | 默认正文 |
| Body-S | 13px | 400 | DM Sans | 次要文字/说明 |
| Caption | 12px | 400 | DM Sans | 时间戳/标签/辅助文字 |
| Mono | 13px | 400 | JetBrains Mono | 代码/命令/路径 |

### 行高

- 标题：1.3
- 正文：1.6
- 代码：1.5

## 七、动效规范

### 时长

| 类型 | 时长 | 缓动 |
|---|---|---|
| hover 反馈 | 150ms | ease-out |
| 按钮按下 | 100ms | ease-in |
| 卡片展开/收起 | 250ms | ease-in-out |
| 页面切换 | 200ms | ease-out |
| 弹窗出现 | 250ms | cubic-bezier(0.16, 1, 0.3, 1) |
| 消息出现 | 300ms | ease-out（从下往上 + 淡入） |
| 工具调用展开 | 200ms | ease-in-out |

### 关键动画

```css
/* 消息出现 */
@keyframes msg-in {
  from { opacity: 0; transform: translateY(8px); }
  to { opacity: 1; transform: translateY(0); }
}
.msg-enter { animation: msg-in 0.3s ease-out; }

/* 流式文本光标 */
@keyframes cursor-blink {
  0%, 50% { opacity: 1; }
  51%, 100% { opacity: 0; }
}
.stream-cursor {
  display: inline-block;
  width: 2px; height: 1em;
  background: var(--accent);
  margin-left: 2px;
  animation: cursor-blink 1s infinite;
  vertical-align: text-bottom;
}

/* 卡片 hover */
.card-hover { transition: transform 0.2s ease, box-shadow 0.2s ease, border-color 0.2s ease; }
.card-hover:hover { transform: translateY(-2px); box-shadow: var(--shadow-md); }

/* 侧边栏项激活指示条 */
.sidebar-item { position: relative; overflow: hidden; }
```

### 减少动画偏好

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```
