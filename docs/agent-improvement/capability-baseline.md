# Vigil Agent 能力基线

> 状态：待在当前工作副本执行首次基线。本文不声称任何未实际运行的测试已经通过。

## 固定架构约束

- Electron 桌面端 + 现有 Python Brain。
- 现有 Provider、Agent 执行器、工具注册与授权、会话/历史/记忆、工作区和插件体系。
- 只允许在现有职责边界内改进；优先保持接口、数据格式与用户数据兼容。
- 不以接入新框架替换 Vigil，不将测试通过等同于真实模型能力通过。

## 指标

每次评测至少记录：
- 通过/失败/超时/未运行的测试数量。
- 失败测试及错误分类。
- Agent 任务完成率（仅在有明确验收标准的行为测试中计算）。
- 工具调用次数、重复调用与无效调用（测试环境能可靠记录时）。
- 总耗时、超时数，以及 Provider 提供时的 token 用量。
- 当前 Git commit、测试环境、Provider 类型（fake/real）和测试命令。

## 基线规则

1. 首次运行结果是测量值，不是预设的通过目标。
2. 不比较不同测试集合、不同模型配置或不同数据集的成功率。
3. 失败、跳过、未运行必须分开统计。
4. Fake Provider 验证的是控制流与契约；不证明真实模型输出质量。
5. 真实模型和外部系统测试应独立记录，未配置时标为未运行。
