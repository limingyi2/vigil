# Vigil v1.0.2

本版本从 `p2-agent-execution` 分支构建，包含 P1 模型适配、Creator 流式与展示记录恢复，以及 P2 Agent 执行循环。

- Agent Run 持久化状态、步骤、部分输出、结果和错误原因。
- 多轮模型与工具执行；步骤、调用次数和时间预算超限时停止。
- 支持取消，重复请求、重连及重复写操作不会重新派发；只读工具可用新调用 ID 读取最新状态。
- 桌面工具任务显示执行阶段，刷新后恢复记录并可取消。
- 保持 Creator 和旧接口兼容，不增加插件能力或权限。

P2 交付记录已随文档清理移除，源码验证见 `git log -- docs/VIGIL_P2_IMPLEMENTATION_REPORT.md`。版本号 `1.0.2`，更新 code `19`。Windows 构建包含重新构建的内置 Brain。

打包验证见 [v1.0.2-validation.json](v1.0.2-validation.json)：6 个嵌入 Python 模块与源码逐项比对；打包后的实际 Brain 完成两次模拟模型调用和一次内置计算工具调用，重复创建不重新执行，完成终态不可被取消覆盖。客户端 ASAR 内版本、界面与 Electron 代理代码与源码一致；安装版和便携版实际归档中的 ASAR、Brain 可执行文件及技能宿主入口均与验证构建一致。

发布资产为 `Vigil.Setup.1.0.2.exe`、`Vigil.1.0.2.exe`、`SHA256SUMS.txt` 和构建信息。两个 Windows 包均未作 Authenticode 签名；未在用户机器覆盖安装或升级。发布流程要求远端资产摘要与本地一致后才公开 Release。
