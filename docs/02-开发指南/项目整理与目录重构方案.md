## 一、当前问题诊断

### 1.1 根目录混乱

根目录有 **30+ 个文件/目录**，混杂了源码、文档、测试脚本、临时文件、备份目录：

| 类别 | 文件/目录 | 问题 |
|------|----------|------|
| 源码 | brain/, client/, wechat_bridge/, admin/ | 应该独立成子项目 |
| 文档 | 00-*.md, 01-*.md, 02-*.md, README.md, CHANGELOG.md | 应该移到 docs/ |
| 测试脚本 | test_*.py（9个） | 应该移到 tests/ 或 _attic/ |
| 临时文件 | *.html, Modelfile_*, model_compare_result_*.json, mcp_screenshot.py | 应该清理或归档 |
| 备份目录 | _backup_*, _attic/, _removed_*, _split/, _bailian_test/, _imgtest/, _selfie_now/ | 应该清理或移到 _attic/ |
| 打包产物 | dist/, build/ | 应该在 .gitignore 里 |
| 第三方 | Windows-MCP/, deepseek-harness/, pet/ | 应该移到 third_party/ 或单独管理 |

## 五、执行计划

### 阶段 1：文档整理（低风险，先做）

1. 创建 `docs/archive/` 目录
2. 将确认过时的文档移到 `docs/archive/`
3. 将根目录的 .md 文档移到 `docs/`
4. 更新 `docs/01-待办清单.md`（整合 00、01、02 三个待办文档）
5. 更新 `README.md`

### 阶段 2：清理临时文件（中风险）

1. 删除 `client/dist_new*` 旧打包目录
2. 删除根目录的测试脚本、临时文件
3. 清理 `_backup_*`, `_attic`, `_removed_*` 等目录
4. 清理 `deploy/` 旧脚本和安装包

### 阶段 3：目录重构（高风险，需确认）

1. 创建子项目目录结构
2. 移动 brain/, client/, wechat_bridge/ 到独立位置
3. 更新所有路径引用（打包脚本、部署脚本、文档）
4. 测试打包和部署流程

### 阶段 4：部署工具精简

1. 合并 `deploy_*_20261009.py` 为统一脚本
2. 创建 `deploy/README.md` 说明每个脚本的用途
3. sshkeys 加入 .gitignore

## 六、注意事项

1. **不要直接删除**：所有删除操作先移到 `_attic/`，确认无误后再删
2. **路径引用**：重构目录后，需要更新：
   - `deploy/vigil-brain.spec` 的 BLOCK 路径
   - `deploy/deploy_client_*.py` 的 LOCAL_EXE 路径
   - `client/package.json` 的 extraResources 路径
   - 所有文档中的路径引用
3. **.gitignore**：确保 dist/, build/, *.log, sshkeys/ 都在 .gitignore 里
4. **备份**：重构前先备份整个项目（或确认 git 已提交）
